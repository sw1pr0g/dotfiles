## Installation

Setup is managed [`dotbot`](https://github.com/anishathalye/dotbot/). Follow
these steps:

1. Decide what you want 
to [`install`](https://github.com/sw1pr0g/dotfiles/tree/main/install): 
comment out `run_dotbot 'steps/...'` that you don't need
2. Run: `bash ./install`

## Local configuration

Some of the used tools requires local configuration. Such as `git` with username and email.

Here's the full list:

1. `~/.gitconfig_local` to store any user-specific data
2. `~/.shell_env_local` to store local shell config, like: usernames, passwords, tokens, `gpg` keys and so on
